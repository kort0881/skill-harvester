# AGENTS.md

## Project purpose

This repository discovers, evaluates, curates and consolidates public Agent Skills from GitHub.

## Safety rules

- Never commit `.env`, API keys, access tokens or credentials.
- Preserve source repository, source path and license metadata where available.
- Do not publish skills that facilitate malware, credential theft, secret exfiltration, destructive operations without safeguards, fraud, or privacy abuse.
- Treat model output as untrusted. Validate JSON and do not execute commands generated by a model.
- Keep raw collected material in `data/raw/` and curated output in `library/skills/`.

## Quality rules

Accepted skills should be practical, self-contained and clear about:
- scope and intended use;
- prerequisites and inputs;
- ordered steps;
- verification or quality checks;
- failure modes or limits where relevant.

## Local commands

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python run.py collect --limit 10
python run.py analyze --limit 5
python run.py consolidate --limit 2
python run.py build-readme
```

On Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py collect --limit 10
```
